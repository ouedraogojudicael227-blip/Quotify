# Quotiify ✨

> **Une citation inspirante, chaque jour.**  
> Site web moderne qui te propose des citations de toutes sortes (motivation, sagesse, amour, succès, vie...) pour t'accompagner au quotidien.

---

## 🌟 À propos

**Quotiify** est une plateforme web simple et élégante qui te permet de découvrir une nouvelle citation inspirante **chaque jour**.  
Que tu cherches de la motivation pour tes études, de la sagesse pour la vie, ou simplement un peu de positivité, Quotiify est là pour toi.

---

## ✨ Fonctionnalités

- 📅 **Citation du jour** mise à jour automatiquement
- 🔍 **Recherche** parmi des centaines de citations
- 🏷️ **Catégories** : Motivation, Sagesse, Amour, Succès, Vie, Amitié...
- ❤️ **Favoris** : Sauvegarde tes citations préférées
- 📤 **Partage** facile sur WhatsApp, Instagram, Twitter/X
- 🌙 **Mode sombre** / Mode clair
- 📱 **Responsive** : Parfait sur mobile, tablette et ordinateur
- 🎲 **Citation aléatoire** à tout moment
