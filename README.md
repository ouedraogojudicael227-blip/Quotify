# Quotify

Une citation inspirante, chaque jour.

Site web + application (PWA). Open source. Pas de compte.

## Lancer en local

```bash
git clone https://github.com/ouedraogojudicael227-blip/Quotify.git
cd Quotify
python3 -m http.server 8080
```

Ouvre `http://localhost:8080` ou `index.html?shell=app`.

## Fonctions

- 60 citations
- Citation du jour selon la langue
- Roue au hasard
- Explorer, favoris, copier / partager
- FR / EN, clair / sombre, hors-ligne

## Branches

- `main` protégée : pas de push direct
- `develop` pour le travail en cours
