# Quotify

Une citation inspirante, chaque jour.

Site web + application (PWA). Open source. Pas de compte.

## Lancer en local

```bash
git clone https://github.com/ouedraogojudicael227-blip/Quotify.git
cd Quotify
python3 -m http.server 8080
```

Ouvre `http://localhost:8080` ou `http://localhost:8080/index.html?shell=app`.

## Fonctions

- 60 citations, citation du jour selon la langue
- Bouton « une autre »
- Compte à rebours jusqu'à minuit
- Explorer par thème et recherche instantanée
- Favoris sans recharger la page
- Copier / partager
- Français et anglais
- Mode clair / sombre
- Hors-ligne après la première ouverture
